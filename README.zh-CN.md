# JSON Viewer

**可视化 · 对比 · 编辑 · 保留原始数据。**

JSON Viewer 是一个无需安装、无需服务器的单 HTML 工具，用于查看 JSON 中的一维曲线、二维标定矩阵、多维数值数组切片与单值参数。支持两个版本并排对比，并通过完整工作副本 C 安全地修改数值。

语言版本：[English](README.md) · [简体中文](README.zh-CN.md) · [Deutsch](README.de.md)

## 快速开始

下载并使用 Chrome、Edge 等桌面浏览器打开 `index.html`。在「单文件」模式导入 JSON 进行可视化，或在「版本对比」模式导入 A、B 两个版本。右上角切换中/英/德界面语言，JSON 中的变量名、路径和原始值始终保持原样。

## 功能

- 自动寻找数值型一维数组、显式 X/Y 曲线、X/Y/Z 矩阵及多维数组，并列出单值参数。
- 1D 折线图、2D 热力图、可旋转/缩放/平移的 3D 曲面；显示坐标轴、采样节点、Z 色阶。
- 3D 鼠标操作：左键拖动旋转，中键拖动平移，滚轮缩放，双击重置。悬停节点读取 X/Y/Z；悬停脊线查看切片，点击可锁定切片，单文件模式的切片表悬浮在画内；双版本对比模式则把切片表放在各自 3D 曲面下方，不再遮挡图形。
- 两版本使用统一坐标范围与色阶，识别修改、新增、删除及未变的参数。
- 编辑时先完整复制源文件到 C；原文件不被更改。支持差异高亮、撤销、重置、退出确认及完整 C JSON 导出。
- CSV / PNG 导出，以及单值参数差异 CSV。
- **一键下载离线 PDF 差异报告**：有差异的曲线和矩阵每个变量独占一页，上方展示 A/B 图形，下方给出两版全量参数表；差异单元格和断点用橙色标记。多个单值差异可合并到一页。报告采用白底；多维数组同一变量的所有切片保持在同一页，必要时使用更高的 PDF 页面。

## 示例和数据结构

[`examples/demo.json`](examples/demo.json) 使用完全合成的数据，包含 X/Y 一维曲线、X/Y/Z 矩阵及单值参数。显式曲线可采用同一对象内的 `SpeedXAxis_F` 和 `ResponseYAxis_F`；二维表增加 `LoadYAxis_F` 以及 `ResponseZAxis_F`（行对应 Y、列对应 X）。

程序也会尝试根据命名和数组长度推测断点与数值的对应关系，但这不是严格的 JSON Schema 校验。实际使用前请核对变量关系与坐标单位。也可以同时上传纯合成数据 [`version-a.json`](examples/version-a.json) 和 [`version-b.json`](examples/version-b.json)，体验差异报告功能。

## PDF 差异报告

在「版本对比」导入 A/B 后，点击工具栏中的「导出 PDF 差异报告」，即可**直接下载 PDF 文件**，无须打印对话框、服务器或外部库。报告始终比较**原始 A/B**，不会混入未导出的工作副本 C。曲线、矩阵每个变量单独一页，图在上、全量表在下；单值项按多条合页。多维数组同一变量的所有切片保留在同一页，该页可能高于普通 A4 横版。PDF 使用高分辨率图片页面，文字不能直接选中或搜索。

## 工作副本与数据安全

导入的 JSON 仅在浏览器本地解析，不会上传至服务器。首次编辑创建完整工作副本 C，后续只修改 C；不相关的字段会保留。对比模式可以明确选择 A 或 B 作为 C 的来源，切换来源需要确认。下载 C JSON 才能把修改保存到本地，工具不会覆盖原始上传文件。

## 已知限制

3D 曲面仅连接原始采样点以便观察，并不代表实际控制软件的插值方法。物理单位可能由变量名推测并附 `(?)`，不能代替参数定义文档。工具不会自动验证断点单调性、`_size_` 字段、应用领域约束或安全限值。浏览器通常不提供文件的绝对父级目录路径，同名文件可人工填写目录标签。
